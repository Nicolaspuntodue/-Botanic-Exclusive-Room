# Botanic Exclusive Room · demo homepage

Demo concept della homepage scroll-driven per Botanic Exclusive Room (Via Roma 126, Pescara).

- Vite + three.js (hero WebGL e acqua della Nave) + GSAP ScrollTrigger + Lenis
- Pescara animata generata con Higgsfield, foto della stanza reali

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # output in dist/
```
